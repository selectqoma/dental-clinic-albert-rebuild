# Dental Clinic Albert rebuild

A reusable dental-clinic website template plus a completed outreach demo for Dental Clinic Albert in Forest, Brussels.

## Local preview

Run a static server from this folder:

```sh
python3 -m http.server 5173
```

Then open `http://localhost:5173`.

## Template notes

The clinic-specific content lives in `data/dental-clinic-albert.js`. The layout in `index.html`, `src/app.js` and `src/styles.css` can be reused for future dental clinic outreach sites.
